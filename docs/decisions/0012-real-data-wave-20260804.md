## Decision

Publish a local, immutable, fixture-fallback real-data pilot for a travel-relevant Flatiron/NoMad/Union Square envelope. Acquire only the approved NYC OTI Building Footprints and NYC DOHMH Restaurant Inspection Results snapshots; fail closed for MTA because its official portal metadata leaves the license unspecified, and defer OSM/Overture payload acquisition to the next approved wave. Do not rerun the earlier 133-batch Manhattan building envelope without a new budget and review.

Pilot envelope: `west=-74.005`, `south=40.738`, `east=-73.982`, `north=40.752` (WGS84; server-side source filter). The existing city adapter's broader study boundary remains an application boundary; the published real release claims only this pilot bbox.

The source registry approves exactly these two IDs for ingestion on 2026-08-04. Building Footprints uses [NYC Open Data overview/terms](https://opendata.cityofnewyork.us/overview/); DOHMH uses the exact [NYC DataMine terms URL](https://www.nyc.gov/html/datamine/html/data/terms.html?dataSetJs=raw), and agency disclaimers remain attached to source licenses and derived artifacts. This decision does not assert a universal open license, citywide completeness, or redistribution clearance beyond the approved local pilot. The MTA [station-complex](https://data.ny.gov/Transportation/MTA-Subway-Stations-and-Complexes/5f5g-n3cz/data) and [entrance](https://data.ny.gov/Transportation/MTA-Subway-Entrances-and-Exits-2024/i9wp-a4ja) records both reported unspecified licenses when checked, so no MTA records were downloaded.

The pilot's `HEIGHT_ROOF` values are recorded as feet-equivalent source measurements and normalized to meters by `0.3048`; raw values and `sourceUnit: "feet"` remain in feature height provenance and attributes. OTI metadata documents `GROUND_ELEVATION` as a NAVD88/LiDAR or photogrammetric elevation but does not establish the numeric field unit, so the ingest records `groundElevationSourceUnit: "unknown"`, preserves the raw value, and leaves `groundElevationMeters` null rather than guessing from the horizontal US-foot CRS.

## Reproducible commands

The acquisition and normalization commands are intentionally bounded and fail closed on existing output, checksum mismatch, unsafe paths, malformed geometry, pending sources, and incomplete object IDs:

```sh
node --experimental-strip-types scripts/acquire-nyc-building-snapshot.mjs \
  --ids data/raw/real-wave-20260804/building-ids-pilot.json \
  --output data/raw/real-wave-20260804/manhattan-building-pilot-20260804.geojson \
  --manifest data/raw/real-wave-20260804/manhattan-building-pilot-20260804.manifest.json \
  --batch-size 250 --timeout-ms 30000

node --experimental-strip-types scripts/normalize-dohmh-pilot.mjs \
  data/raw/real-wave-20260804/dohmh-restaurant-pilot-20260804.socrata.json \
  data/raw/real-wave-20260804/dohmh-restaurant-pilot-20260804.records.json \
  2026-08-04T03:12:00.000Z

pnpm nyc:building-ingest -- --input data/raw/real-wave-20260804/manhattan-building-pilot-20260804.geojson --output data/generated/nyc-building-footprints/manhattan-pilot-20260804 --checksum cf311cd757564fe9cc75f8dc6a60d42c643bb402db4d811f448338ff5f6a18fb --terms-url https://opendata.cityofnewyork.us/overview/ --input-crs EPSG:4326 --release null --capture 2026-08-04T03:08:28.735Z --updated 2026-08-03T02:59:51Z --ingested-at 2026-08-04T03:08:30.000Z --vertical-datum 'GROUND_ELEVATION NAVD88 when documented; HEIGHT_ROOF relative to source ground; source uncertainty preserved' --height-unit feet --ground-elevation-unit unknown
pnpm poi:ingest -- --input data/raw/real-wave-20260804/dohmh-restaurant-pilot-20260804.records.json --output data/generated/dohmh-restaurant-inspections/manhattan-pilot-20260804 --checksum cfec0c148d438dd1ecde5e5bb0ed1b1cfc8ff9851b360df63e79745b79ebf011 --ingested-at 2026-08-04T03:12:30.000Z
```

## Quarantine and rejected sources

The interrupted full-city requests produced `.partial` files under `data/raw/real-wave-20260804/quarantine/`; they are explicitly excluded from all manifests and releases. Only the worker's own acquisition processes were terminated, with TERM first; no unrelated process was touched. MTA, OSM, and Overture are not silently substituted by fixture records in the real release.

Adapter and catalog validation covered SHA-256 checks, exclusive-create immutable outputs, object-ID completeness, WGS84 geometry normalization, source approval, inspection-vs-place separation, deterministic source ordering, partitioned catalog assembly, and pending-source refusal.
